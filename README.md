# Scrum
IGME 580 Repository for Scrum

Scrum is a fast paced, first person, arena shooter in which players battle it out in a construction zone (?) to declare a winner. Before every round, each player will have a randomized selection of structures, hazards, weapons, and traps that they can add to the map in any way they like. This adds another layer of chaos throughout the game and encourages creativity and strategy when approaching each round. After each round, the map will return to how it appeared right before the round began.
